# 두 번째 포스트

마크다운의 다양한 기능을 테스트해봅니다.

## 강조

**굵은 글씨**와 *기울임꼴*을 사용할 수 있습니다.

## 코드 블록

```typescript
interface User {
  name: string;
  age: number;
}

const user: User = {
  name: '홍길동',
  age: 30
};
```

## 테이블

| 이름 | 나이 | 직업 |
|------|------|------|
| 홍길동 | 30 | 개발자 |
| 김철수 | 25 | 디자이너 |

## 이미지

이미지도 삽입 가능합니다 (로컬 파일이나 URL).

이제 블로그를 자유롭게 사용할 수 있습니다!
